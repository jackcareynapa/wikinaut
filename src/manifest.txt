# Build order for wikinaut.user.js — see scripts/build_userscript.py.
#
# These fragments share ONE lexical scope (the userscript IIFE), so there are no imports:
# every fragment can see every other fragment's top-level names. src/header.js is not
# listed here — it is the ==UserScript== metadata block and is emitted outside the IIFE.
#
# ORDER IS LOAD-BEARING and is not a stylistic choice. Function declarations hoist, but
# several top-level `const` initializers run at evaluation time and read earlier ones:
# SETTINGS_DEFAULTS reads PALETTE.accent, and the CSS template literal interpolates
# PALETTE_CSS_VARS, TYPE, and CONFIG. Reordering config.js/styles.js relative to their
# dependents throws a TDZ ReferenceError on load. init.js must stay last: it ends with the
# init() call that starts the script.
